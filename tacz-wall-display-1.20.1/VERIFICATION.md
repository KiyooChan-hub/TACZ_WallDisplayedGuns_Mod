# Forge 1.20.1 迁移验证

日期：2026-09-15。基于 1.21.1 版本 0.4.0 移植，发布版本 0.4.0。

## 环境与产物

- Minecraft 1.20.1 / Forge 47.4.21 / TACZ 1.1.8-hotfix。
- 本机 NVIDIA RTX 4070 Laptop；隔离客户端加载本机枪包、Embeddium 0.3.31、Cloth Config、Packet Fixer 3.3.2、RuOK。
- 构建和运行使用本机 JDK 21.0.12.1；`--release 17`，所有发布类的 class major version 均为 61。未另行实测 Java 17 JVM。
- 正式包：`tacz-wall-display-1.20.1-forge-0.4.0.jar`，74,162 字节。
- SHA-256：`bc8db1ae7793660bbb722a9433629bf9edd633e3d778804c9b16acef5efd9d50`。
- Forge 重混淆已执行；正式包由本机已安装的 production Forge 加载器实际运行，不仅是开发环境运行。测试 JAR 独立，未进入正式产物。

## 结果

1. 13 项单元测试全部通过，零失败、零跳过。
2. 背包和工作台合成栏共 13 个位置：正反转换、普通取出、Shift 合成、满背包、取消合成、动态替换输入均通过。枪械名称、弹药、配件、未知 NBT、磁盘保存、网络同步及不可变快照均通过。
3. Forge 专用服务端启动通过；额外挂载的测试 capability 值 42 经转换及序列化后完整恢复，原枪完整序列化 NBT 相等。100 种不同枪械原型、294 个被该版本 TACZ 接受的配件及原枪掉落通过。
4. 六面放置、支撑移除后保留、硬度 0.5、徒手生存破坏返回一支原枪、创造破坏无掉落通过。真实客户端六面共 18 次操作、18 次音效、飞行 Shift 非蹲伏翻面、副手持物、客户端姿态同步通过。
5. SCAR-L、AK47、M4 URGI、带配件 SCAR-L 和三种瞄具与 TACZ 原生 FIXED 渲染逐顶点比较通过；材质、UV、法线及顶点数量匹配。最大相对位置误差约 2.1×10⁻⁷ 格，贴墙间隙约 0.001 格。截图确认全息瞄具、倍率镜、图标和六面姿态可见。
6. 100 支普通枪和 100 支三配件枪稳定观察及近距离移动均无持续几何上传。19 次局部增删仅产生 19 次局部上传；100 支不同姿态枪的 32 次姿态编辑未重新捕获 TACZ 模型。
7. 正式包 100 原型预加载：冷进入 3173 ms、再次进入 2535 ms、资源重载 2987 ms；三轮各采样首次转头起的 210 帧，模型捕获和上传增量均为零，100 支可见。加载失败和超时均为零。
8. 正式包到达新区域：在摄像机背后准备 100 个新快照，单帧最多捕获一个模型、上传两个批次，241 帧后就绪；随后转头无新增捕获或上传，100 支可见。

## 帧时间与范围

测试设置上限 60 FPS。普通枪近距离移动 1074 帧的中位数 16.76 ms、P95 18.02 ms、最大 20.24 ms；三配件枪移动 1071 帧为 16.82 / 18.15 / 68.87 ms；局部编辑 1250 帧为 16.75 / 18.19 / 76.27 ms。捕获/上传计数证明静态网格与局部重建机制成立，不能把它解读为整合包全程没有任何帧时间尖峰。

测试使用隔离原生 1.20.1 存档和关键渲染模组，未测试完整整合包所有模组组合及光影。既有枪包含失效索引、缺失脚本及部分跨版本配件兼容差异；测试样本依据 1.20.1 实际接受的索引和配件调整，不修改用户枪包。朝向校准沿用已有 558 条显示模型记录，本轮未重新逐一目检全部枪包条目。
