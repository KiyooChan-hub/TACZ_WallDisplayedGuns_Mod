# TACZ Wall Display — Forge 1.20.1

这是 1.21.1 装饰枪模组功能同步到 Minecraft 1.20.1 的 Forge 版本（0.6.28，与当前主版本功能同步）。需要 TaCZ 和 Java 17；本模组不限制 TaCZ 版本号，仍以 1.1.8-hotfix 为编译基线。Forge 47.4.21 为推荐版本，不设本模组的最低平台版本限制。Create、WTHIT 与 Mesh Loader 为可选兼容项。

## 0.6.28 同步：Mesh 枪体及配件

同步 1.21.1 的 Mesh 枪体、配件静态捕获和共享瞄具状态恢复。仅在装饰枪 FIXED 快照期间接入 Mesh Loader 的顶点输出，绕过实时 VBO 绘制；继续复用材质、光照、姿态、墙面批次及 Create 移动缓存。存档格式、原枪数据、摆放模式与加载保护均不变，旧枪在更新后重启客户端重新生成缓存，无需拆除重摆。

依赖审计：两版 TaCZ、Forge/NeoForge 与 javafml 的运行时范围均为 `[0,)`，没有额外代码层面的模组版本比较。Mesh Loader 不设版本门槛且不打包进产物；Gradle 中的具体版本仅为构建基线，不是玩家运行时限制。保留各自 Minecraft 目标版本约束；不锁版本不等同于所有依赖历史/未来版本均已验证。

验证环境：TaCZ 1.1.8-hotfix、Mesh Loader Forge 0.1.8、Forge 47.4.21，Java 17 字节码。`gradlew --offline test build` 包含正式产物重混淆。测试涵盖已有逻辑、四把本地 duyupack 网格、三角形拓扑与可选接口签名。未启动游戏；旧存档实际画面、配件/光影、Create 与未安装 Mesh Loader 的运行时回归待验收。1.21.1 已有正常生效的用户反馈，本次没有替换该版本。

## 0.6.27 同步：入世持枪初始化、保护收尾与提示

同步 1.21.1 的 0.6.26、0.6.27 功能：安全的 TaCZ 时间同步与握手消息、快捷栏槽位同步不再被加载保护误丢弃。拔枪请求合并一次，在解除保护前绑定最终槽位；客户端配对恢复正常拔枪动画与冷却，不重复发包，不重放开火或近战。

修复取消传送误挂保护、旧会话与迟到回复干扰等路径，补齐释放确认重发和无会话查询；`/kill` 的专用伤害不再被加载保护拦截。每次连接世界后发送一次本地摆放提示，显示实际绑定键；切维度和重生不重复。在 `config/tacz_wall_display-client.toml` 设置 `showPlacementHintOnJoin = false` 可关闭。

协议为 `activation-5`，双端须同时更新。保留默认 10 秒可配置预加载预算、60 秒安全跳过、摆放禁火及原有枪械数据。Forge 共用网络频道中的消息类型通过 TaCZ 已注册编码器识别，不硬编码序号。详见 [0.6.27 验证记录](../VERIFICATION-0.6.27.md)。以下旧版本条目仅作历史记录。

## 0.6.25 同步：激活超时安全跳过

入世或切维度时，装饰枪激活等待达到 60 秒后改为安全跳过预加载，不再因该计时器强制断线。客户端尚未回应时，服务端继续保护玩家；收到客户端偏好或跳过请求后，才发送释放通知并恢复游戏。TaCZ–JEI 自身的加载时间不受影响。双端握手协议为 `activation-3`，客户端与服务端须同时更新。下方旧版本的 300 秒断线说明仅为历史记录。

## 0.6.24 同步：解除 TaCZ 版本门禁

客户端和服务端仍须安装对应 1.20.1 Forge 的 TaCZ，但不再因其版本号不等于 1.1.8-hotfix 而直接拒载。静态模型捕获使用 TaCZ 内部接口；解除加载门禁不代表其他版本已通过运行兼容性测试。

## 0.6.23 同步：入世握手与预加载回退

服务端每 2 秒重发尚未确认的激活请求；客户端等待目标维度就绪再处理，重复请求不重置会话。`OFF` 不会因装饰枪模型捕获失败而误断线。`LOADING` 在模型失败或初始场景准备超时后请求服务端跳过，收到释放确认才恢复游戏；已发送准备完成通知时不会误触发预加载时限。客户端 `config/tacz_wall_display-client.toml` 中的 `preloadTimeoutSeconds` 默认 10 秒，可设为 1–240 秒。以下 300 秒截止时间与 `activation-2` 为 0.6.23 的历史行为，当前规则以上方 0.6.25 说明为准。验证范围与结果见 [0.6.23 验证说明](VERIFICATION-0.6.23.md)。

## 0.6.21 同步

玩家在摆放模式下成功进入其他维度时，服务端会关闭该模式；新维度加载完成、恢复控制前，客户端复用手动关闭时的聊天信息和关闭音效。登录、同维度重生及取消的维度传送不会触发自动关闭。测试与部署记录见 [0.6.21 验证说明](VERIFICATION-0.6.21.md)。

## 0.6.20 同步

以下为旧版行为记录；当前超时及失败回退规则以上方 0.6.23 说明为准。初始装饰枪通过服务端有限集合握手，在原版地形界面完成模型和 GPU 准备后激活玩家。旧版加载期间保留网络与区块传送，并挂起玩家玩法；失败或 120 秒超时会断开。客户端可选择 LOADING 或 OFF，双端均需更新到匹配协议。

模型使用有预算的缓存，维度切换保留部分静态 GPU 批次。运行期间编辑单元持续复用共享局部网格；旋转只更新矩阵，取消停止编辑后定时重建整组模型的路径。独立绘制调用随编辑枪数增加，首次冷外观与光照变化仍可能有帧峰值。

## 使用方式

按 P 切换枪械自由摆放模式；可在原版“按键键位”的 TACZ 分类中修改。模式内，手持 TACZ 真枪右键方块可摆放对应装饰枪，配件、弹药和自定义数据会保留。左键按原版方式破坏方块，装饰枪空手左键一次可破坏，生存模式掉落原枪。对准装饰枪时，左 Alt＋右键翻面；左 Alt＋上滚轮逆时针旋转，左 Alt＋下滚轮顺时针旋转，方向不受翻面影响。手持真枪右键装饰枪可按原版邻格规则继续摆放。创造模式中键选取装饰枪会得到原枪。

真枪与装饰枪不再通过合成互相转换。旧装饰枪物品在读档或进入容器时转换为真枪，且不能作为方块再次放置；命令或其他模组仍可能生成其注册物品。原有存档内已摆放的装饰枪继续显示和使用。装饰枪可六面放置，也可悬空。

模式 UI 包含右上角操作说明、禁火提示和边缘效果。持枪在未破坏方块时左键不会开火；连续误触会提示并按既定频率播放空枪音效。客户端配置 `maxRenderDistance` 默认 512 格，`-1` 表示不按距离剔除；区块本身仍受游戏视距限制。

模型与贴图直接读取 TACZ 和已安装枪包。静态网格按区域缓存并预热，支持 Create 强力胶移动结构及 WTHIT 显示原枪名称。两者不是硬性前置。

## 构建与验证

`gradlew.bat test build` 构建 Java 17 发布包；`gradlew.bat -Psmoke runClient` 在隔离世界运行当前摆放功能测试。预热压力测试 `-Psmoke -PwarmupSmoke runClient` 需要先在隔离运行目录提供 `saves/warmup-stress/level.dat`，否则会明确报缺失并退出。测试客户端音量为音乐 0、主音量 0.5、其他分类 1.0。测试 JAR 不部署到正式实例。

0.6.23 的测试结果见上方验证说明；旧版完整整合包曾通过一轮摆放、高频旋转、邻枪持续绘制和停止编辑后不重建静态批次的运行检查，重新读档和资源重载未作为本次同步验收。

此版本使用 1.20.1 的物品与存档格式，不支持将 1.21.1 世界直接降级。
