# TACZ Wall Display

TACZ 静态装饰枪模组的独立开发仓库，当前位置为 `D:/FORK/TACZ_WallDisplayedGuns_Mod`。

- [Minecraft 1.21.1 / NeoForge](tacz-wall-display-1.21.1/README.md)：默认功能维护版本。
- [Minecraft 1.20.1 / Forge](tacz-wall-display-1.20.1/README.md)：仅在用户明确要求时同步更新。
- [CurseForge 发布说明](tacz-wall-display-1.21.1/CURSEFORGE.md)
- [依赖评估](tacz-wall-display-1.21.1/DEPENDENCIES.md)
- [迁移记录](MIGRATION.md)

两个版本均保留原有 Gradle 工程布局，分别进入子目录使用 Gradle Wrapper 构建。Minecraft 实例、TACZ 依赖及已发布制品的位置保持原样，具体要求见各子工程说明。

此仓库只维护装饰枪模组及其测试，不包含 HK416D、L119A2 等独立枪包工程。开发和提交规则见 [AGENTS.md](AGENTS.md)。
