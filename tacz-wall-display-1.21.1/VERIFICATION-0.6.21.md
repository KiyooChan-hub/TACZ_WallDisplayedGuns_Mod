# 0.6.21 跨维度自动退出摆放模式（2026-09-29）

## 实现

- 成功触发玩家维度变更事件且摆放模式开启时，服务端立即清除权威模式状态，并在当前加载会话中记录关闭标记。
- 关闭标记随既有加载 `release` 消息发送，不依赖加载期间会被玩法保护拦截的普通模式包。
- 客户端收到放行后立即解除摆放状态和 TACZ 禁火拦截；聊天与关闭音效在加载界面消失后的首个客户端 tick 播放，复用手动关闭路径。
- 登录、同维度重生、资源重载、已关闭状态及取消的维度传送不会重复触发。

## 验证

- `gradlew.bat --offline test build -PactivationSmoke compileActivationSmokeJava` 成功；30 项 JUnit，零失败、零错误、零跳过。
- NeoForge 21.1.248 独立服务器与真实客户端完成五次加载会话，覆盖登录、主世界与下界往返、跨维度死亡重生及连续传送。349 次等待期伤害、目标和推动保护检查通过。
- 首次跨维度前同时启用双端摆放模式；维度事件后服务端状态关闭，放行后客户端状态关闭，模型失败 0，加载队列和 GPU 批次队列均清空。
- 客户端截图确认加载界面消失后显示 `Gun placement mode: Off`，摆放 HUD 不再显示。关闭提示复用 `MODE_CLOSE` UI 音效调用。
- 测试实例音乐 0、主音量 0.5、其余声音分类 1.0；未修改正式实例个人设置。
- 正式 JAR 不含 activation/smoke 测试类。
