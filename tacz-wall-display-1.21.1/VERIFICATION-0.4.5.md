# 0.4.5 N4 弹匣重叠修复（2026-09-19）

仅更新 Minecraft 1.21.1 / NeoForge，1.20.1 未改动。本机已安装 0.4.4，本次升级至 0.4.5。

## 原因与修改

新建独立模型的 `additional_magazine` 默认可见，TACZ 会使用该节点再次绘制弹匣。普通持枪帧结束时会执行 `cleanAnimationTransform()` 隐藏换弹用备用弹匣，而原装饰捕获直接渲染新模型，遗漏了这一步。

在 GunMeshes 的独立模型捕获前调用 TACZ 的状态清理，位于现有枪包显隐修正之前。仍让 TACZ 根据原枪配件选择标准/扩容弹匣；不改写快照，不触碰玩家实际手持模型，不增加逐帧动画或捕获任务。

## 验证

- `gradlew.bat --offline clean test build -Psmoke smokeJar` 成功，13 项单元测试零失败。

- 以明确隐藏备用弹匣节点的独立捕获作为单弹匣参考，不以产品初始化方法作为测试预期。
- 0.4.4 实际客户端复现：四档外观均与“备用弹匣可见”的重复几何完全一致。
- 0.4.5 实际客户端打开上一步原样保存的八枪存档，四档外观的全部顶点属性与材质均等于单弹匣参考；正面/翻面正常，无需重新摆放。
- 检查原枪组件及快照保持一致，手持模型备用弹匣显隐未被修改，同一快照复用静态网格。
