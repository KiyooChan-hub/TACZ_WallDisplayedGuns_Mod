# TACZ Wall Display — 0.2.1

目标环境：Minecraft 1.21.1、NeoForge 21.1.248、Java 21、TACZ 1.1.8-hotfix-r6。

0.2.1 补齐瞄具外壳与目镜环的独立渲染路径。0.2.0 的装饰枪数据兼容，更新并重启后自动重新捕获，已放置的装饰枪无需重新合成或摆放。

## 使用

1. 将装好配件的 TACZ 真枪**单独**放入背包 2×2 或工作台 3×3 合成栏的任意一格，取出装饰枪。无需额外材料。
2. 装饰枪右击坚固墙面放置。显示转换时的枪械及配件静态外观；物品图标使用原枪的 slot 贴图。
3. 在生存模式拆除装饰枪，或移除支撑墙，掉落保存原枪数据的装饰枪。创造模式直接破坏遵循原版不掉落规则，中键复制保留完整内容。
4. 将装饰枪单独放入任一合成栏，取出原真枪。配件、弹药、膛内子弹、射击模式、自定义名称及其他持久物品组件随原枪保存和还原。
5. 正反向都是一个输入换一个输出。装饰枪不可堆叠，不会额外生成真枪或配件。更换输入会更新预览；关闭合成界面仅返还尚未使用的输入。

自 0.2.0 起已移除 0.1.x 的创造标签和 gun-id 预设功能。新方块 ID 为 `tacz_wall_display:decorative_gun`；旧 `wall_gun` 方块、物品及 `gun_id` 组件不注册、不迁移，旧装饰内容废弃。旧方块不能兑换真枪。更新需移出旧 JAR 并完全重启游戏。

这是包含方块、数据组件和配方的模组，多人游戏客户端与服务端均需安装匹配版本和 TACZ。动态配方由服务端计算，适用于原版两种合成栏；不需要切石机。配方是特殊动态配方，不为每个枪型生成配方书条目。

## 数据和渲染

- 仅注册一个通用方块／物品。不枚举枪包制作装饰枪目录；从实际投入的原枪读取完整物品快照，保留真实 gun/display ID 和配件。
- 快照使用 Minecraft ItemStack 数据组件编码，数量标准化为一把。存储所有持久组件，不手工列举或重建默认枪。服务端方块保存、物品掉落、客户端同步均保留该快照。
- 枪包资源仍需安装。直接使用 TACZ 按原枪选择的 display 和纹理，不复制 PNG、不导出图集。资源缺失时显示缺失标记，原枪快照不因渲染失败而删除。
- 原枪数据相同的装饰枪共享一次捕获的静态几何。缓存按完整不可变快照区分，配件、皮肤不同不会误用同一模型；非外观数据不同也可能分别缓存，以优先保证未知枪包的正确性。
- 原枪本体使用独立模型实例，捕获 FIXED 展示姿态和配件几何后保存不可变顶点；不持续执行枪械动画或逐骨骼渲染。
- 任意角度、UV、法线和发光属性保留，剔除零面积隐藏面片后贴墙，最近有效面距墙 0.001 格；保持 TACZ 展示框的尺寸与朝向。
- 沿用固定 2×2×2 单元、按材质合批的持久 GPU 缓冲：每批最多 8 个锚点，单面墙最多 4 把。静止和相机移动不重建；增删仅更新涉及的小批次。
- `/wallgun_stats` 显示捕获数、失败数、上传数及提交批次的枪数。F3+T 或离开世界清理缓存。

## 当前边界

- 装饰外观固定为合成时的装配。要改配件，先还原真枪、正常装配，再重新转换。
- 首次遇到新的完整快照会同步捕获模型，可能短暂卡顿；大量不同快照和材质仍占用内存、显存和绘制次数。
- 不模拟射击、动态动画、瞄准镜视野或激光光束等实时武器效果。附属枪包自定义渲染逻辑仍需逐包验证。
- 选择框位于宿主方块，伸出的枪管没有独立选中框，过密摆放可能重叠。
- 实测使用独立存档及内置服务器，没有修改用户已有存档；外置多人服务器尚未实机联机测试。

## 验证和构建

`gradlew.bat build --offline` 运行几何和批次测试并构建发布 JAR。

`gradlew.bat runClient -Psmoke --offline` 在 `run-client` 新建独立测试世界，验证真实合成菜单、数据持久化及网络编解码、四面放置和掉落、配件模型与独立记录的 TACZ 实际缓冲提交数据的一致性（参考过程不启用产品捕获器），并截图比较三种瞄具的真实展示框外观，并进行 100 把枪的静态／运动／编辑压力测试。记录保存在 `run-client/verification`。必须检查新生成的 `SUCCESS.txt`，启动任务退出码不能代替测试结果。

测试代码在 `src/smoke`，不会打入发布 JAR。测试实例复制了正式实例的枪包及 Sodium、Iris、Complementary v4.7.2、RuOK、Cloth Config 和相关配置。

默认从 `E:/GAME/Minecraft/Minecraft 1.21.1/.minecraft/mods` 引用 TACZ JAR。可用 `-PminecraftInstance=路径` 指向另一实例。TACZ 和枪包资源不会打入本模组。
