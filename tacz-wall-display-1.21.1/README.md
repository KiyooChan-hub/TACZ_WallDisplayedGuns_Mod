# TACZ Wall Display — 0.1.0 原型

目标环境：Minecraft 1.21.1、NeoForge 21.1.248、Java 21、TACZ 1.1.8-hotfix-r6。

## 使用

1. 将 `tacz-wall-display-1.21.1-0.1.0.jar` 放入实例 `mods`，完全重启客户端。
2. 创造模式打开 **TACZ 装饰枪（原型）** 标签，选择枪型，右击坚固方块的侧面放置。
3. 中键复制会保留枪型。破坏支撑墙会移除装饰枪。
4. `/wallgun_stats` 显示当前会话的模型烘焙次数、失败数、GPU 上传次数、最近一次渲染的枪数及绘制次数。
5. F3+T 重载资源会清理并重新生成静态缓存。枪包清单以 TACZ 实际加载成功的公共枪械索引为准。

这是带方块和存档数据的模组；多人游戏也需要服务端安装。当前部署和运行验证针对客户端及其内置服务器，没有修改已有世界。

## 实现

- 固定注册一个方块/物品，每把枪使用独立的 `tacz_wall_display:gun_id` 物品组件和方块实体 `GunId`。
- 方块实体没有 ticker。渲染回调只提供可见实例、朝向和光照信息。
- 每个枪型第一次使用时创建独立的 TACZ 枪械模型，使用标准 FIXED 展示姿态捕获静态顶点。捕获后只保留不可变几何。
- 捕获窗口通过 ThreadLocal 严格限定，并以 finally 清理。窗口之外的 TACZ 渲染行为不变。
- 直接复用 TACZ 原 RenderType / 纹理资源，不导出 PNG、不生成枪械贴图图集、不降低贴图分辨率。
- 同一区段、同一材质的静态顶点合并为持久 GPU 顶点缓冲；实例、光照或资源改变才重建。
- 缓存闲置后释放 GPU 缓冲；离开世界和资源重载时清理。
- 原始模型的任意角度、UV、法线和发光标志保留，未转换为受 22.5° 限制的普通元素 JSON。
- 物品栏及手持使用原枪包的二维 slot 图标，避免打开创造栏时加载所有高精度模型。

## 原型范围

- 创造模式使用；没有配方和生存获取/掉落机制。
- 每个 gun ID 提供默认展示外观，包括标准渲染所产生的内置部件；不提供自由配件组合和皮肤选择。
- 以 FIXED 姿态为基础自动居中、贴墙；超大模型等比限制在约 2.8×1.8×0.7 格范围内。不同枪包的原始缩放仍可能需要后续校准。
- 选择框位于宿主方块，枪管伸出部分没有独立占位或选中框。摆放过密可互相重叠。
- 首次看到新枪型会同步烘焙，可能有一次短暂卡顿。大量不同材质仍需要多次绘制，几何和贴图仍消耗内存/显存。
- 未支持的模型显示缺失标记并记录错误，保留清单与原 ID。
- 不把“100 把同材质合成一次绘制”解释为“所有场景只需一次绘制”，也未给出相对原展示框的 FPS 增益承诺。

## 验证

`gradlew.bat build --offline` 运行几何捕获测试并构建。

`gradlew.bat runClient -Psmoke --offline` 使用 **run-client 内复制的枪包** 创建独立平坦世界：

- 验证有效枪械索引与创造栏集合相等。
- 验证 NBT 保存/读取、复制枪型、四面放置和支撑移除。
- 生成 12 把枪的正面/斜侧面/资源重载截图。
- 检查静止场景的 GPU 上传计数不增长。
- 验证同一区段的 100 把同材质枪合并为一次绘制。
- 验证原枪包物品图标。

测试模组位于 `src/smoke`，**不会打入发布 JAR**。测试结果写入独立实例的 `verification` 目录；不得把测试目录作为正式实例运行目录。

已验证的渲染组合包括 Sodium 0.8.13-beta.2、Iris 1.8.14-beta.1 和 ComplementaryShaders v4.7.2。测试采用复制的用户光影设置；不代表整合包内所有模组组合都已验证。

## 构建路径

默认从 `E:/GAME/Minecraft/Minecraft 1.21.1/.minecraft/mods` 引用 TACZ JAR。可通过 `-PminecraftInstance=路径` 指向另一实例。TACZ 和枪包资源不会打入本模组。
