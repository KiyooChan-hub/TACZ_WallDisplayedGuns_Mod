# 0.6.0：自由摆放交互更新

目标：Minecraft 1.21.1、NeoForge 21.1.248、TACZ 1.1.8-hotfix-r6。仅更新 1.21.1。

- P 模式键移入原版控制设置的 TACZ 分类；移除模式键位与调整物品 config。旧配置文件在部署时备份并移出正式实例。
- 装饰枪零硬度；模式内保持原版左键破坏。任意主手物品或空手右键装饰枪转向；左 Alt＋滚轮翻面；持真枪左 Alt＋右键装饰枪按点击面邻格放置。
- 成功放置沿用石头／圆石放置声。模式开关使用原版 toast 音源，复现当前整合包 ExtraSounds 的物品栏开关音效，无需依赖 ExtraSounds。
- 提示框包含最终中文操作指南，右端固定、宽度上限为 GUI 宽度三分之一、50% 黑色背景、必要时换行；屏幕边缘渐变在四角连续。

验证：`test build smokeJar -Psmoke` 通过。隔离 NeoForge 客户端以 `-Psmoke -PplacementSmoke runClient` 实际进入测试世界，检查旧物品迁移、六面放置、零硬度、创造中键与生存掉落；客户端网络操作验证真枪右键放置、空手右键转向、点击面邻格放置、翻面请求及生存空手首次攻击秒破。简体中文和英文 HUD 均截屏检查，四角渐变连续。测试实例音乐为 0、主音量为 0.5，正式玩家实例音量未修改。

修饰键与鼠标滚轮的物理组合未由自动客户端直接模拟；对应客户端分支经编译，服务端的放置和翻面请求已在隔离客户端验证。正式整合包中其他模组的输入冲突仍需玩家实机确认。
